# Client（示教器）

示教器 Android 工程在独立仓库 [`ShiJiaoQi-New/`](ShiJiaoQi-New/)，不跟 WMesh 混在一个 git 里。

- 远程：`git@gitee.com:pangliang071/ShiJiaoQi-New.git`
