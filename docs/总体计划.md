# WMesh 总体计划（到可验证版本）

> 当前状态：阶段 1（账号体系）、阶段 2（节点身份与离线授权）已通过业务验证并纳入基线。阶段 3～5 有工程落库，业务未通过；阶段 6 未开。  
> 仓库按两个工程分开放：`global/` 跨厂总控、`factory/` 厂内；各自只有 `frontend/` 与 `server/`，Go 模块和迁移只在 `server/` 内，部署文件（Dockerfile / docker-compose / Makefile）放在各工程根，可独立构建、部署、升级。  
> 推进方式：每阶段「规格 → 实现 → 验证 → 基线」；未验证不得当完成物。工程矩阵跑通 ≠ 业务通过；业务通过以业务方验证为准。  
> 需求依据：`docs/平台架构核心需求.md`（已锁定）。

**当前方向（已冻结）：** 不进入阶段 6。从阶段 3 起按业务指出的问题逐项验证、修复、完善；一项通过再下一项。阶段 3～5 全部业务通过后，才开阶段 6（集成版本 V0.1）。

**通道选型（已冻结，厂↔WAN 认领基座已落地）：** 厂↔WAN 用 WSS（厂出站认领），厂↔Client 用 MQTT over TLS。规格：`docs/specs/节点通道.md`。建厂发建厂码，厂端贴码并设密码；不再要求 WAN 反打厂内网。

**正文加密（工程已落地，业务未验）：** WAN 明文主库；出口必须应用层加密；厂侧密文 + 最长 24 小时租约。规格：`docs/specs/正文加密.md`。
