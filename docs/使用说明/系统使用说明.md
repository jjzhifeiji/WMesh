## 1. 资产要解决什么问题

| 痛点 | 做法 |
| --- | --- |
| 工艺、工程在示教器里按文件夹存，换机就乱 | 每条资产有 **稳定身份与编号**；工程只 **引用工艺 ID**，不靠路径 |
| 总部要标准工艺，又怕参数外泄 | **平台 / 厂 / 个人** 三级；**不可复制** 的平台工艺：厂内 **只看名录，不看参数** |
| 厂服、示教器磁盘被拷走 | 工艺正文在厂库 **只存密文**；下发到示教器也是 **密文包**，工位用时才在内存里解开 |
| 老盘里成百上千条要进系统 | **旧文件导入**：选示教器工艺/工程目录，收成厂级或平台级资产 |
| 厂里做好要上升到全集团 | **升档**：复制出新条目到上一级，**不改** 下级原件 |
| 现场不能常连厂网 | **发布** 后把已授权资产打成密文同步到示教器；离线仍可焊已同步内容 |

## 2. 资产模型

### 2.1 工艺与工程

- **工艺**：焊接参数配方（电流、电压、摆动等），可复用；**保密主要针对不可复制的平台工艺参数**。
- **工程**：一次焊接作业，含多条 **焊道**；焊道绑 **工艺 ID**，**不把工艺参数写进工程文件**。工程正文在厂内 **不保密**（焊道、坐标、绑了哪条工艺可见）。

### 2.2 三级归属

| 级别 | 谁制作 | 典型用途 |
| --- | --- | --- |
| **个人级** | 示教器 / 个人账号 | 个人库；可复制时可升为厂级 |
| **厂级** | 厂内管理端 / 全厂账号 | 本厂共享；可复制时可升为平台级 |
| **平台级** | 云端 | 跨厂标准；厂内多为只读引用 |

### 2.3 状态与可复制

| 状态 | 含义 |
| --- | --- |
| 未发布 | 工艺未发布，不可被工程依赖、不参与下发 |
| 可用 | 已发布，可引用、可参与组包与密文下发 |
| 已停用 | 不可再改、不可升档 |

- **可复制**（仅工艺）：允许被上一级 **升档复制**；否则不能升上云。
- **不可复制**（常见为平台标准工艺）：**不因已下发给本厂而放宽**——厂内仍 **不能升档、不能改可复制、不能把参数展示给人看**。
- 升档永远是 **新建/覆盖上级副本**，不动下级原件。

### 2.4 加密与保密（核心）

下面说的是 **工艺/工程正文**（参数、焊道数据），不是列表上的名称、编号、状态、修订。

| 谁 / 在哪 | 工艺正文 | 工程正文 |
| --- | --- | --- |
| **云端（平台级）** | 平台工艺在云端侧维护与查看（含参数） | 平台工程可看焊道与依赖 |
| **厂内 Web** | 本厂自建厂级/个人级：可看 **参数**；**不可复制的平台工艺**：详情里 **不显示参数**（提示「不可复制，不显示工艺参数」），列表仍可见名称、状态、修订、编号 | **可看** 焊道、依赖工艺、绑定的工艺名/ID |
| **厂内数据库** | **只存密文**，不存工艺明文 | 按级别与策略存储；工程不按「不可复制工艺」那套藏正文 |
| **示教器（Client）** | 同步到本机的是 **密文包**；焊接时在内存用明文，**磁盘上不落工艺明文** | 同步密文；焊道与作业所需字段在授权范围内使用 |
| **运输** | 云端→厂、厂→示教器：正文走 **应用层加密**（不只靠 HTTPS） | 同左 |

**和界面操作的对应关系：**

1. **发布**：把「可用」资产纳入本厂可下发范围；之后操作员在示教器 **同步** 拿到的是 **密文**，不是厂内详情里那种可直接浏览的明文表单（不可复制平台工艺在厂内本来也看不到参数）。
2. **组包 / 下发**：工程闭包带上引用的工艺；不可复制平台工艺仍以密文形式进包，**不会因为已经下发就改成可复制或在厂内 Web 里露出参数**。
3. **升档**：仅 **可复制且已发布** 等条件满足的工艺/工程才能从厂级升到平台；不可复制 **永远不能** 靠升档把参数「送上云给人改」来绕过（升档走的是复制出新平台条目那一套，见云端 **从工厂升档**）。
4. **旧文件导入**：进库后同样走加密存储；平台级不可复制工艺在厂内的可见性规则 **与新建/升档下来的一致**。

**工程没有「不可复制藏正文」**：保密争议集中在 **平台工艺参数**。点云/图片等现场文件在厂内 OSS，**不上云**，与工艺密文下发是另一条线（见 4.4）。

## 3. 云端：平台工艺与平台工程

侧栏 **资产** → **平台工艺** / **平台工程**。测试云端为 **表格列表 + 行内操作**；点 **详情** 打开 **文件详情**（只读）；改内容用 **编辑**。云端是 **平台级明文维护点**（相对厂库密文而言）。

### 3.1 列表页

![平台工艺列表](./images/wan-processes.png)

![平台工程列表](./images/wan-projects.png)

| 区域 | 作用 |
| --- | --- |
| 搜索 / 状态 / 来源 / 排序 | 查平台资产名录 |
| 列 **可复制** | 决定厂级能否 **升档** 到平台，也关联厂内是否能把参数当「自家工艺」那样看 |
| **详情** | 看元数据 + 工艺 **参数** / 工程 **焊道**（云端可见正文） |
| **发布** / **停用** | 控制能否被引用、参与下发 |
| **从工厂升档** | 仅升 **可复制、已发布** 的厂级副本到平台 |
| **新建** | 在平台级新建 |

页头说明：平台只维护平台副本；厂级原件仍在各厂；升档时正文相同则跳过，有变更则覆盖平台侧。

### 3.2 文件详情（工艺）

![平台工艺文件详情](./images/wan-process-detail.png)

元数据：编号、工艺 ID、状态、**可复制**、修订、来源厂、时间。下半 **参数** 按工艺模版只读展示（云端可见）。标 **不可复制** 的平台工艺下发到厂后，厂内 **看不到这一段**，但示教器仍可在授权下用密文焊接。

### 3.3 文件详情（工程）

![平台工程文件详情](./images/wan-project-detail.png)

多 **依赖工艺** 摘要；正文 **焊道** 列表及每条绑定的工艺 ID。工程不参与「可复制保密」，但引用的 **不可复制工艺** 仍只在密文/授权链里出现，厂内 Web 不展示其参数。

### 3.4 工艺模版 / 工程模版

![工艺模版](./images/wan-templates.png)

![工程模版](./images/wan-project-templates.png)

定义字段与焊道结构；**不改** 已有资产已落库的正文，只影响新建与后续编辑。

### 3.5 旧文件导入 / 从工厂升档

![云端旧文件导入](./images/wan-import.png)

导入与升档后的平台/厂级资产，仍遵守 **可复制、不可复制** 与 **厂内参数不可见** 规则；升档通道上正文仍按加密规范处理，云端落库平台级工艺为可维护副本。

## 4. 厂内：工艺与工程

侧栏 **资产** → **工艺** / **工程**。 **文件树 + 文件列表 + 文件详情** 三栏；右栏与云端 **详情** 同源字段，但 **不可复制平台工艺的参数区会被挡住**。

![厂内工艺](./images/factory-processes.png)

![厂内工程](./images/factory-projects.png)

### 4.1 中栏与搜索

搜索名称、编号；按焊接类型筛选；新建文件夹 / 新建工艺或工程。

### 4.2 文件详情

| 字段 | 说明 |
| --- | --- |
| **级别** | 个人级 / 厂级 / 平台（引用） |
| **参数**（工艺） | 厂级/个人级可看；**不可复制平台工艺** →「不可复制，不显示工艺参数」 |
| **焊道**（工程） | 可看焊道与绑定工艺；工程本身不藏正文 |
| **发布** | 发布后进入 **密文下发** 链路，供示教器同步 |

### 4.3 旧文件导入（厂级）

![厂内旧文件导入](./images/factory-import.png)

结果为厂级资产，入库为密文；发布规则同上。

### 4.4 现场文件

Client 上传的点云、图片等在厂内浏览；存厂内对象存储，**不上云**，与工艺密文策略分开管理。

## 5. 资产与保密相关流程

| 目标 | 步骤 |
| --- | --- |
| 标准工艺下到厂但不泄密 | 云端建 **不可复制** 平台工艺并发布 → 厂内见名录、**不见参数** → 发布 → 示教器 **密文同步** |
| 本厂工艺共享/上云 | 厂级 **可复制** 工艺发布 → 需要时云端 **从工厂升档** |
| 示教器开焊 | 厂网登录同步 **密文** → 工位连机械臂 WiFi → 内存解密作业；**工艺参数不进示教器明文文件** |
| 看清一条资产 | 云端 **详情** 或厂内点文件：厂级/个人工艺看参数；平台不可复制工艺 **只看元数据** |

## 6. 其它（与资产无关，简述）

与工艺/工程正文无关，但和「谁能登录、哪台机能焊、版本是否一致」有关；**不改变** 第 2.4 节的保密与密文下发规则。

| 模块 | 云端（WAN） | 厂内（Factory） |
| --- | --- | --- |
| **工厂** | 建工厂、发 **建厂码**；停用/启用/注销名录；看各厂在线与版本 | **认领** 建厂码并激活；本厂数据与 WAN 名录分离 |
| **账号与组织** | 仅 WAN 管理员账号；**不** 管厂内人员、组织、日常密码 | 超管建人、组织、角色与权限；人员只能登本厂 |
| **设备（Client）** | 登记设备、分给工厂；跨厂视图 | 本厂设备列表；给已登记设备签 **运行许可**（与资产密文包一起约束谁能焊） |
| **软件更新** | 发布厂服/示教器安装包与版本 | 拉取升级；与工艺/工程 **正文包** 分开下发 |
| **审计** | 跨厂操作留痕（无密码、无工艺明文） | 本厂关键操作留痕 |
| **报表** | 跨厂焊次等汇总（**不含** 厂内人员明细） | 按工程、人员、组织查本厂焊次与统计 |
| **示教器** | — | 厂网 **同步密文** → 工位连机械臂 WiFi 作业；登录/扫厂服不要求当时连着臂 |
