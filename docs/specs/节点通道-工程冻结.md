# 节点通道工程冻结（厂↔WAN MQTT）

> 业务合同以 `节点通道.md` 为准。本文件只冻怎么落地。  
> 不改阶段 1～5 允许/拒绝。厂↔Client MQTT 仍未铺。

---

## 1. 本圈

把厂↔WAN 日常控制面改成 MQTT 小指令 + HTTPS 拉正文。修订升高只在应用服务发一次指令。建厂认领走 HTTPS 交厂钥。

## 2. Broker

- WAN 进程内嵌 MQTT Broker（MQTT 3.1.1），监听 `WMESH_MQTT_ADDR`（默认 `:1883`）。
- 不另起 Mosquitto。本厂 Broker 以后另内部署，不和 WAN 共用。
- QoS 1。厂端 `CleanSession=false`，`ClientID` = 工厂 UUID。
- WAN 重启后内存会话可空；厂端 CONNECT 后拉索引补齐，不把 Broker 当业务权威。

## 3. 鉴权

CONNECT：`Username` = 工厂 UUID，`Password` = 厂钥对 `wmesh-wan-mqtt-v1 || factoryId || unix 秒` 的签名（允许 ±300 秒）。

ACL：只允许 `wan/{自己}/down` 订阅、`wan/{自己}/up` 发布。

HTTPS 拉正文用同一套签名头：`X-WMesh-Factory`、`X-WMesh-Time`、`X-WMesh-Sign`。

建厂认领（未交钥，不用签名头）：

- `POST /v1/channel/enroll` 用建厂码换身份，不消耗建厂码。
- `POST /v1/channel/claim` 再验建厂码后交厂钥，作废建厂码。

## 4. 指令

下行 JSON，无正文：

| typ | 厂端做什么 |
| --- | --- |
| `closure` | HTTPS 拉密封闭包，走 `AcceptPlatformDelivery` |
| `template` | HTTPS 拉模版，走 `AcceptTemplateDelivery` |
| `software` | HTTPS 拉软件包，走 `AcceptSoftwareDelivery` |
| `retract` | `RetractPlatformDelivery` |
| `client_bind` / `client_void` | 走接受绑定 / 作废 |
| `factory_state` | 治理只向前 |
| `lease` | 应用内容租约 |

索引 `GET /v1/channel/index`：当前该厂该有的指令清单（无正文）。回连先拉索引再逐条拉。

## 5. 通知落点

`mutatePlatform` 成功且状态为可用/停用 → 一条 `closure`。删除 → `retract`。模版/软件/绑定在各自 Service 成功后各发一条。HTTP 不再组全文下发。

## 6. 完成定义

改名/发布后在线厂能收到指令并拉到新修订；离线厂上线后经会话或索引补到同一修订。软件包不进 MQTT。认领走 HTTPS 交厂钥。
