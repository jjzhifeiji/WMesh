# 控制器 Client：从旧实现迁到新规范（对照清单）

> 不是 C0 规格验收。C0 矩阵写的是**目标允许/拒绝**；下面是 `client/`（cloud 6.1）相对目标还差什么，供实现圈逐项改。  
> 已拍死、不再确认：`processPath` → `processId`；厂→本机密文、登录领钥；工程/工艺现有字段不另改形状。

做法：在 `client/` 上改，包名沿用，覆盖 6.1。圈次仍按 C1→C9。

| 差什么 | 现在 | 改成 | 圈 |
| --- | --- | --- | --- |
| 工程/工艺从哪来 | `/sdcard/ShiJiaoQi` 文件树 | 本机袋闭包成员；旧文件只走厂端导入 | C1、C3；导入在厂 |
| 工艺挂钩 | `processPath`、多层内嵌 `process` | 只写 `processId`，⊆ `deps` | C3 起；厂端导入改写 |
| 落盘 | 明文 JSON、`allowBackup=true` | Room 信封；钥与明文只在已登录内存 | C1 |
| 谁能用 | MAC 注册码 | 设备识别号绑系统 Client；本厂账号登录 | C1 |
| 连厂 | 无 | MQTT + HTTPS 拉正文 | C2 |
| T 排 | 独立 Activity + 标准库文件夹 | 第四份工程模版 + `gapBands` 引用 | 模版在 WAN/厂；焊在 C8 |
| 标准盘 / CDN zip | 本机全量工艺 | 禁止；只用闭包里的工艺 | C3 |
| 焊接协议与几何 | 现网 | 原样留 | C4～C8 |

厂内夹具已有的（只拷拒激活、焊中不切换）接到 App 本机袋即可，不重做语义。
