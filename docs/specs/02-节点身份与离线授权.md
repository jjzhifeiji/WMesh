# 第二圈规格：节点身份、密钥边界与离线授权

> 前置：`01-账号体系.md` 已完成并通过验收。  
> 依据 `docs/平台架构核心需求.md` §2、§3、§4、§6、§7.3、§7.4。  
> 验收展开：`02-节点身份与离线授权-验收矩阵.md`。落地：`02-节点身份与离线授权-工程冻结.md`。

---

## 1. 本圈目标

Client 断网时，只凭本地已持凭证判断：节点能不能运行、当前人员能操作什么、能用到何时、归属哪个厂；回连后按 Factory 的最新意图收敛。  
WAN 管跨厂节点信任；Factory 签发与撤销本厂 Client 及人员离线授权；Client 不连网也能做本地验证。

---

## 2. 本圈不做

账号、自定义组织、在线角色管理的既定语义不在本圈重做。本圈不做 Robot 身份、TPM、资产稳定身份、工程/工艺闭包、内容签名算法、通信与同步协议、单条工艺/工程的细权清单。

---

## 3. 节点身份

| 谁 | 身份含义 | 谁承认 |
| --- | --- | --- |
| WAN | 全局信任根 | 自身 |
| Factory | 一厂一个，只管本厂 | WAN |
| Client | 一台现场节点一个，只属一个厂 | 所属 Factory（受 WAN 约束） |

Robot 本圈不纳入平台身份。  
未绑定到本厂的 Client，本厂不得签发。Client 换厂视为新绑定，旧厂凭证立即作废；已连网必须收敛，离线最迟用至过期。

---

## 4. 密钥边界

- 信任锚在 WAN。Factory 只有本厂签发权，不能给其他厂或自己签发平台级信任。
- Client 只持本机身份材料、已签发的节点/人员离线授权、验证上级用的公开信任材料，以及本机获准人员所需的最小认证验证材料。
- Client 不得缓存全厂账号库；密钥与工艺/工程等数据分开存放。
- 一期不承诺抗 Root 后提取运行态密钥；发现异常只留痕，不自动清密钥、不停机。

---

## 5. Client 离线运行凭证

一张 Client 离线运行凭证必须能回答：谁签发、签给哪个 Client、属于哪个厂、能否运行、有效起止、授权修订号。

| 动作 | 规则 |
| --- | --- |
| **签发** | Factory 对其已绑定 Client 签发；未绑定或他厂 Client 拒签 |
| **本地验证** | 断网只查本地凭证与公开信任材料：签发方可信、持有方是本机、本厂、未过期、本地未见撤销 |
| **过期** | 过期后不得新开受保护操作或接新下发；进行中的焊接不因过期中断 |
| **撤销** | 意图在 Factory；已连网立即拒绝新操作，离线继续用到过期或本地拿到撤销声明 |
| **更新** | 只接受更高授权修订；旧的过期、已撤销或低修订凭证不得覆盖新意图 |

签发时间与有效期在线跟上级/服务器时间，离线才用本机时间；一期不承诺抗改钟。

---

## 6. 人员离线授权

Factory 只可给本厂有效账号签发绑定到特定 Client 的人员离线授权。授权至少包含：

- 签发 Factory、账号稳定身份、绑定 Client；
- 当前可选的 OrgUnit 分配及各自祖先路径；允许“Factory 直属”时须明确写入；
- 允许的固定角色及组织作用域；
- 生效与失效时间、授权修订号。

Client 离线登录必须同时验证人员认证要素与人员离线授权；单独持有其中之一不得冒充账号。人员授权复制到其他 Client、其他账号或其他厂均无效。

离线可执行范围取以下交集：

1. 人员离线授权允许；
2. Client 离线运行凭证允许；
3. 本机已持资产及其所属、级别与策略允许。

任一不允许即拒绝。人员授权或 Client 授权任一过期，不得新开受保护操作；正在进行的焊接不中断。

账号停用、角色收回、人员组织分配变化或组织树调整属于 Factory 最新意图：在线立即生效；离线无新意图时按未过期的本地授权继续，拿到更新或回连后收敛。Client 只接受更高授权修订，旧授权不得恢复已停用账号、已移除角色或旧组织状态。

离线操作必须从本地有效授权中选定一个 OrgUnit 工作上下文或“Factory 直属”；事实保存账号、Factory、所选 OrgUnit 及其祖先路径快照，回连后不得根据当前人员分配或当前组织树重写，也不得计入未选择的其他 OrgUnit。

## 7. 验收

以下均须能用“给定条件 → 允许 / 拒绝 / 继续，并产生何种归属与审计”判定，不连真设备、不测协议。

1. **本厂签发**：已绑定本厂的 Client，Factory 可签发；验证通过，允许运行。
2. **他厂拒签**：Factory 不能给未绑定或他厂 Client 签发。
3. **跨厂无效**：厂 A 的凭证到厂 B 的 Client 上验证失败；拷贝厂 A 数据到厂 B 的 Client，不能运行。
4. **只拷文件无效**：只拷贝凭证或工艺/工程文件到另一台未持对应本机身份材料的 Client，验证失败。
5. **节点过期**：Client 凭证已过期 → 拒绝新开受保护操作；正在焊接 → 继续。
6. **节点在线撤销**：已连网 Client 收到撤销后，新操作立即拒绝。
7. **节点离线撤销**：未连网、本地无撤销声明 → 凭证未过期仍可用；回连后按撤销收敛。
8. **节点更新不回滚**：已接受较新撤销或缩权修订，再收到旧凭证 → 保持拒绝。
9. **时间来源**：能连通时改本机钟不影响按服务器时间判定；断网才用本机钟。
10. **异常不自动停机**：模拟 Root / 改钟被发现 → 留痕，不自动清密钥或停用节点。
11. **有效人员离线登录**：本厂有效账号在绑定 Client 提供正确认证要素，人员授权未过期且许可满足 → 允许范围内操作。
12. **人员授权不可复制**：只复制人员授权，或复制到另一 Client / 账号 / 工厂 → 登录或操作拒绝。
13. **双重许可**：人员允许但 Client 无效，或 Client 允许但人员无权 → 均拒绝；两者及资产策略都允许才允许。
14. **人员与组织变更收敛**：在线停用账号、收回角色、调整人员 OrgUnit 分配或组织树 → 新操作按新意图；离线无新意图且授权未过期 → 按原范围；回连后按更高修订收敛。
15. **人员旧意图不回滚**：Client 已接受较新停用、缩权、组织分配或组织树修订，再收到旧人员授权 → 保持新意图。
16. **离线统计不漂移且不重复**：人员离线授权含多个 OrgUnit，本次选择 A 产生事实 → 只归 A 的发生时路径；回连前人员分配或组织树变化，不重写该事实，也不计入其他未选节点。
