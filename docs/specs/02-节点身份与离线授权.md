# 第二圈规格：节点身份、密钥边界与离线授权

> 前置：`01-账号体系.md` 已完成并通过验收。  
> 依据 `docs/平台架构核心需求.md` §2、§3、§4、§6、§7.3、§7.4。  
> 验收展开：`02-节点身份与离线授权-验收矩阵.md`。落地：`02-节点身份与离线授权-工程冻结.md`。

---

## 1. 本圈目标

Client 断网时，只凭本地已持节点凭证判断：这台设备能不能运行、能用到何时、归属哪个厂；回连后按最新意图收敛。  
WAN 管跨厂设备归属；Factory 签发与撤销本厂 Client 运行凭证。本厂有效账号默认能上本厂设备，厂里不另签发人员授权。

---

## 2. 本圈不做

账号、自定义组织、在线角色管理的既定语义不在本圈重做。本圈不建 Client 进程、不向 Robot 下指令、不做 TPM、资产稳定身份、工程/工艺闭包、内容签名算法、单条工艺/工程的细权清单。厂↔Client 的 MQTT 通道不在本圈。

---

## 3. 设备身份

| 谁 | 身份含义 | 谁承认 |
| --- | --- | --- |
| WAN | 全局信任根 | 自身 |
| Factory | 一厂一个，只管本厂 | WAN |
| Client | 一台现场设备一个，只属一个厂 | 所属 Factory（受 WAN 约束） |

Client 有固定识别号（全局唯一身份 ID，不当显示名）和给人看的名字（可改，不当身份）。设备先在 WAN 名录建档，由 WAN 分给工厂；厂端经通道自动落库，人不用抄公钥或修订号。本机钥匙由 Client 自己生成，首次在本厂上线再登记公钥。

Robot 本圈不纳入平台身份。  
未绑定到本厂的 Client，本厂不得签发。Client 换厂视为新绑定，旧厂凭证立即作废；已连网必须收敛，离线最迟用至过期。

---

## 4. 密钥边界

- 信任锚在 WAN。Factory 只有本厂签发权，不能给其他厂或自己签发平台级信任。
- Client 只持本机身份材料、已签发的节点运行凭证、验证上级用的公开信任材料。不得缓存全厂账号库。
- Client 不得缓存全厂账号库；密钥与工艺/工程等数据分开存放。
- 一期不承诺抗 Root 后提取运行态密钥；发现异常只留痕，不自动清密钥、不停机。

---

## 5. Client 离线运行凭证

一张 Client 离线运行凭证必须能回答：谁签发、签给哪个 Client、属于哪个厂、能否运行、有效起止、授权修订号。

| 动作 | 规则 |
| --- | --- |
| **签发** | Factory 对其已绑定 Client 签发；未绑定或他厂 Client 拒签 |
| **本地验证** | 断网只查本地凭证与公开信任材料：签发方可信、持有方是本机、本厂、未过期、本地未见撤销 |
| **过期** | 过期后不得新开受保护操作或接新下发；进行中的焊接不因过期中断 |
| **撤销** | 意图在 Factory；已连网立即拒绝新操作，离线继续用到过期或本地拿到撤销声明 |
| **更新** | 只接受更高授权修订；旧的过期、已撤销或低修订凭证不得覆盖新意图 |

签发时间与有效期在线跟上级/服务器时间，离线才用本机时间；一期不承诺抗改钟。

---

## 6. 人员与设备

本厂有效账号默认能在本厂已绑定设备上操作，权限由厂内角色与组织分配决定，不由厂里再签一张人员授权。设备归哪厂由 WAN 定。

离线可执行范围取以下交集：

1. 本厂有效账号（密码正确、未被停用）；
2. Client 离线运行凭证允许；
3. 本机已持资产及其所属、级别与策略允许。

任一不允许即拒绝。账号停用、角色收回立刻按厂库；节点凭证过期不得新开受保护操作，正在进行的焊接不中断。

离线操作必须选定一个 OrgUnit 工作上下文或“Factory 直属”；事实按当时厂库分配写入路径快照，回连后不得根据当前人员分配或当前组织树重写。

---

## 7. 验收

以下均须能用“给定条件 → 允许 / 拒绝 / 继续，并产生何种归属与审计”判定，不连真设备、不测协议。

1. **本厂签发**：已绑定本厂的 Client，Factory 可签发；验证通过，允许运行。
2. **他厂拒签**：Factory 不能给未绑定或他厂 Client 签发。
3. **跨厂无效**：厂 A 的凭证到厂 B 的 Client 上验证失败；拷贝厂 A 数据到厂 B 的 Client，不能运行。
4. **只拷文件无效**：只拷贝凭证或工艺/工程文件到另一台未持对应本机身份材料的 Client，验证失败。
5. **节点过期**：Client 凭证已过期 → 拒绝新开受保护操作；正在焊接 → 继续。
6. **节点在线撤销**：已连网 Client 收到撤销后，新操作立即拒绝。
7. **节点离线撤销**：未连网、本地无撤销声明 → 凭证未过期仍可用；回连后按撤销收敛。
8. **节点更新不回滚**：已接受较新撤销或缩权修订，再收到旧凭证 → 保持拒绝。
9. **时间来源**：能连通时改本机钟不影响按服务器时间判定；断网才用本机钟。
10. **异常不自动停机**：模拟 Root / 改钟被发现 → 留痕，不自动清密钥或停用节点。
11. **有效人员登录**：本厂有效账号在本厂设备提供正确密码，节点凭证允许 → 允许操作（不限特定设备）。
12. **不可跨账号或跨厂**：密码不对、他厂账号、或他厂设备袋 → 登录或操作拒绝；本厂另一台设备 → 允许登录。
13. **双重许可**：人员允许但 Client 无效，或 Client 允许但人员无权（角色/资产桩）→ 均拒绝；两者及资产策略都允许才允许。
14. **人员与组织变更**：停用账号、收回角色、调整分配或组织树 → 新操作按厂库；历史事实不改写。
15. **（已废止）** 不再签发人员授权快照，无旧授权可回滚。
16. **离线统计不漂移且不重复**：人员分配在节点 A，本次选择 A 产生事实 → 只归 A 的发生时路径；之后改分配或组织树变化，不重写该事实。

## 8. 当前落地（基线）

- WAN 管理端：设备名录（起名、分配、改分、改名）。识别号由系统给出，不当显示名。
- 厂内管理端：云端分来的设备经通道自动出现；超管改名、签发或撤销运行许可；未上线（无公钥）不能签发；列表显示当前使用人。
- 厂端不手填身份、公钥或修订。WAN 经 WSS 推 `client_bind` / `client_void`，厂端走同一「接受绑定 / 作废」入口。验收夹具仍可直调，不测套接字。
- 签发须本厂有效超管、绑定有效、本机公钥已登记。
- 不签发人员离线授权；该表已删除。本厂有效账号用密码登录本厂设备，权限跟厂库角色；厂库记下当前使用人。
- 本机钥匙由 Client 自己生成，首次在本厂上线再登记公钥。私钥不进 WAN、不进厂库、不进审计。
