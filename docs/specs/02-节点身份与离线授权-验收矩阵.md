# 节点身份与离线授权验收矩阵（规格圈冻结）

> 权威语义仍以 `docs/specs/02-节点身份与离线授权.md` 为准。  
> 本文件把 §7 十六条冻成可独立判定的场景：条件 → 允许 / 拒绝 / 继续 → 归属 → 审计。  
> 不连真设备，不测协议、界面、工艺/工程内容签名。  
> 第 7 圈必须按本表自动化跑通后，节点身份才能纳入基线。WAN 编号在 `global/server/internal/service`，厂内与本地验证编号在 `factory/server/internal/service`。

## 共用夹具

名称只用于读场景，验收必须按稳定身份引用。

| 对象 | 含义 |
| --- | --- |
| W | WAN 唯一管理员 |
| 厂 A / 厂 B | W 已创建的两家工厂 |
| SA-A / SA-B | 两厂已激活的初始超级管理员 |
| P-A | 厂 A 有效操作员，可有多个组织分配 |
| Client-A1 | 本机身份材料已生成、拟属或已属厂 A 的现场节点 |
| Client-B1 | 拟属或已属厂 B 的现场节点 |
| 未绑 Client | 已有本机身份材料，WAN 尚未绑到任何厂 |
| 本机袋 | 夹具里的本地持有物：本机密钥、公开信任材料、已持凭证/授权、连通标记、进行中焊接标记、本机钟 |
| 资产桩 | 本机是否允许用某条已持资产；不是真工艺/工程 |
| 事实桩 | 离线产生的最小运行事实，字段与账号体系相同 |

归属字段（事实桩）：创建账号、所属 Factory、选定 OrgUnit（直属则空）、发生时祖先路径快照（直属则空）。回连后不得按当前分配或当前组织树改写。

审计必有：事件身份、操作者稳定身份（无法识别则空）、Factory、目标、结果（允许或拒绝）、时间来源（`server` 或 `local`）。  
连通时时间来源为服务器钟；断网为夹具本机钟。日志不得出现口令、私钥、完整令牌。

未写归属的场景，归属为“无新事实”。

## 歧义冻结（只补会分叉的点）

1. **本圈不建 Client 进程。** 本地验证是应用服务里的纯判定，夹具持有「本机袋」。不测 HTTP / MQTT / 真设备。
2. **WAN 是跨厂绑定权威。** 一台 Client 同一时刻只属一个 Factory。未绑定不得签发。换厂 = WAN 改绑并升高绑定修订；旧厂绑定作废。
3. **厂内只认本库已接受的绑定。** WAN 绑定声明由测试夹具写入厂库（模拟送达，不测协议）。本库无绑定、绑定已作废、或声明指向他厂 → 拒签。
4. **签发人是本厂有效超级管理员。** 其他厂内角色不能签发或撤销节点运行凭证、人员离线授权。
5. **本机身份材料是 Client 密钥对。** 公钥在绑定时登记。只拷凭证/授权/资产文件、没有对应本机私钥 → 验证失败。
6. **人员离线授权是签发时快照。** 写入：账号身份、绑定 Client、当时可选 OrgUnit 及祖先路径、是否允许 Factory 直属、当时角色与作用域、起止时间、授权修订号、该人的口令验证材料。离线不查厂库账号表，不得下发全厂账号库。
7. **离线登录必须两样都过：** 本机袋里的人员授权 + 该人认证要素（登录名与口令对照授权内验证材料）。只持其一不得冒充。
8. **修订只向前。** 每个 Client 一条节点修订；每个（账号，Client）一条人员修订。只接受严格更大的修订。撤销/缩权/停用/改分配/改组织树，都体现为更高修订。旧凭证不得覆盖新意图。
9. **连通标记在夹具上。** 已连网：新撤销/新修订立即参与判定，时间用服务器钟。未连网：本地没有的撤销声明不生效，时间用本机钟。
10. **进行中焊接是夹具标记。** 过期或撤销时：标记为进行中 → 该次焊接继续，不得新开受保护操作；无此标记 → 新开与继续均按拒绝。
11. **资产策略本圈只用桩。** 第三项许可 = 本机资产桩允许。真工艺/工程细权不测。
12. **异常只留痕。** 模拟 Root 或改钟被发现 → 记审计，不自动清密钥、不停用节点、不中断进行中焊接。
13. **组织树按一棵 `org_units` 计。** 路径快照是发生时的节点身份与名称；不依赖组织类型词典。

## 本圈规格完成定义

上表覆盖 §7 每一条，判定式统一为“条件 → 允许 / 拒绝 / 继续 → 归属 → 审计”，歧义已按上文冻结。  
第 2～6 圈只实现能支撑本表的最小能力；第 7 圈按编号 0.1～16.3 全跑通后，才能把节点身份纳入基线。本阶段不做管理端与协议。
