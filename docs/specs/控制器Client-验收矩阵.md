# 控制器 Client 验收矩阵（C0）

> 权威以 `docs/specs/控制器Client.md` 为准。本圈只书面判定，不连真设备、不写 App。  
> 编号 C0.* 供规格验收；实现圈另用应用服务 / 本机袋夹具落地，不得放宽本表。

| 编号 | 条件 | 允许 / 拒绝 | 归属 | 审计 |
| --- | --- | --- | --- | --- |
| C0.1 | 包名沿用 `com.gbndt.shijiaoqi` 覆盖 6.1 | 允许；现场只这一份 App | 同一应用身份 | 无 |
| C0.2 | 覆盖后未导入的 `/sdcard/ShiJiaoQi` 工程/工艺 | 拒绝读取、拒绝激活、拒绝按路径焊接 | 旧文件不当本机袋 | 拒绝痕迹；无正文 |
| C0.3 | 系统已发 Client UUID，登记时读到设备识别号，本厂绑定有效且该号未绑他机 | 允许；该 Client 钉死该设备号 | 设备号属该 Client | `client_register` 允许 |
| C0.4 | 注册时读不到设备识别号 | 拒绝 | 绑定与本机袋不变 | `client_register` 拒绝 |
| C0.5 | 读到的设备号已钉在本厂另一台未作废 Client | 拒绝 | 两台原件不变 | `client_register` 拒绝 |

| C0.7 | 换臂：重新注册读到新设备号 | 允许；旧号作废，新号钉上 | 仍是同一 Client 身份 | `client_register` 允许 |

| C0.8c | `cache_scope=current` 离线且无当前工程信封 | 拒绝激活 | 袋不变 | 拒绝 |

| C0.9 | 退出或 App 销毁 | 允许；内存钥与明文销毁 | 磁盘仍是信封 | 无正文入审计 |

| C0.11 | 空 `processId` | 允许；不进 `deps` | 按写入口 | 允许 |
| C0.12 | 按 T 排模版添加一条焊缝 | 允许；字段是 T 排自己的（含 `gapBands`），`templateId` 为该份 | 新元素 | `create_asset` / 改正文 |
| C0.13 | 单层 `templateId` 的元素带了 `gapBands` 或坡口点 | 允许写入（改正文不套模版）；激活/焊接不当 T 排 | 原元素仍是单层 | 无 |
| C0.14 | T 排 `gapBands[].rootProcessId` / `capProcessId` 非空但不在 `deps` | 拒绝 | 原件不变 | `update_asset` 拒绝 |
| C0.15 | 工程正文再写 `processPath` 或内嵌工艺参数 | 拒绝 | 原件不变 | 拒绝 |
| C0.16 | 厂端导入：工艺文件先入库再映射工程路径 | 允许；厂级资产；`processId` ⊆ `deps` | 新厂级工艺/工程 | `import_legacy` 允许 |
| C0.17 | 导入时某条 `processPath` 找不到对应已入工艺 | 拒绝整份工程；已入工艺保留 | 该工程不存在 | `import_legacy` 拒绝 |
| C0.18 | 现场 App 扫描本地文件树做导入 | 拒绝 | 本机袋不变 | 拒绝 |
