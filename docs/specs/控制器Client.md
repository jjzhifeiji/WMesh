## 1. 本圈目标

把现场示教器收成 WMesh 的 Client：一份 App 覆盖安装 6.1；谁允许注册/登录/激活说清楚；工程只引用工艺身份；T 排是独立模版；旧文件只从厂端迁。

本圈交付是规格与验收矩阵。不写 `client/` 代码，不接真机，不铺 MQTT。

## 2. 本圈不做

## 3. 底线（无先后）

- **一份 App。** 包名 `com.gbndt.shijiaoqi`，覆盖 6.1。不并行第二套示教器。
- **设备识别号从设备读。** 不是人填的，也不是平台 Client UUID。系统仍发 Client 身份与短码；登记把读到的设备号绑死在这台上。
- **工程只引用。** 焊道写 `processId`；组包认 `deps`。禁止 `processPath`，禁止把电流电压嵌进工程。
- **现场不持游离工艺盘。** 只持已授权闭包里的工艺成员。`ShiJiaoQi/processes` 与 CDN zip 不当真相。
- **磁盘无正文。** 本机袋信封；明文与解封钥只在已登录进程内存。
- **写工程强制引用 ⊆ 依赖。** 空引用除外。WAN / 厂 / Client 同一口径。
- **正文形状不另改。** 工艺参数、焊道点列/位姿/多层偏移/包角几何保持现有字段；只把 `processPath` / 内嵌参数换成 `processId`。T 排是新增一份模版，不改单层字段。密文与过站领钥已拍，不再确认。

## 4. 工程放哪、包名

代码在仓库 `client/`（Android 工程根），从 `cloud` 源码迁入。`applicationId` / `namespace` 沿用 `com.gbndt.shijiaoqi`。覆盖安装后旧外部存储文件树**不再读取**；要再用必须先走厂端导入。

关备份：`allowBackup=false`。禁止用系统 Keystore 做成开机自动解库。

## 5. 三堆：平台 / 焊接域 / 丢掉

| 堆 | 进什么 | 不准进什么 |
| --- | --- | --- |
| **平台** | Client 身份与短码、本机钥、节点凭证、人员登录、MQTT、过站重封、Room+SQLCipher、闭包缓存与激活、个人级发号与待发 | 焊道几何、Lua、手柄点动 |
| **焊接域** | 现网协议与时序、单层/多层/包角/T 排几何、采集、模拟/起弧/暂停继续、附加槽、14 套工具、安装姿态、外轴、手柄、在线微调、8083 状态 | 文件树身份、全量工艺目录、MAC 注册码 |
| **丢掉** | `license.key`、CDN 标准库当真相、`ProcessStorage`、三套复制粘贴当唯一结构、明文 HTTP 更新当信任根 | — |

本机设置（工具坐标、点动方位、速度倍率、外轴开关）跟机不跟工程，不得存工艺正文。

打开工程 = 激活本机袋里恰好一份已授权闭包，不是打开文件夹。选工艺 = 闭包成员下拉。

## 6. 设备识别号与注册

控制器（平板 App）与机械臂一对一。注册时必须从设备读到识别号（现网是控制盒一类硬件号），向本厂登记并绑到**系统已给出的**那台 Client 上。

| 条件 | 允许 / 拒绝 |
| --- | --- |
| 已读到设备号，本厂已接受且未作废该 Client 绑定，该号尚未绑到本厂另一台 Client | 允许登记；该 Client 钉死这个设备号 |
| 读不到设备号 | 拒绝注册、拒绝当这台设备用 |
| 读到的号已绑在本厂另一台未作废 Client | 拒绝（一对一） |
| 这台 Client 已钉过别的设备号，本次读到的不同 | 拒绝；换臂须走重新注册，成功后旧号作废、新号钉上 |
| 未绑定、他厂、绑定已作废 | 拒绝登记、拒签节点凭证、拒下发、拒登录领钥 |
| 用设备号顶替平台 Client UUID 或短码 | 拒绝 |

换臂必须重新注册。人不绑死某一台；登录规则仍按 `厂端到控制器.md`。

一期同一控制器同一时刻只保留一份人员登录会话：后登成功则厂端只留新会话（已拍的换人能登、同一人只留一台）。是否允许多人**同时**在线仍见文末未决，实现不得先做多人并行会话。

## 7. T 排是第四份工程模版

空库四份独立工程模版：单层焊道、多层焊缝、包角、**T排对接**。各带自己的字段表和修订。已有库不自动插入第四份；由 WAN 管理员新建，不改已有三份正文。

T 排禁止写进单层模版当作业种类：执行只认 `templateId` 为 T 排那一份的元素。单层元素上即使多写了 `gapBands` 也忽略，不当 T 排焊。

焊接时按测得间隙匹配 `gapBands`：先同 `layer` 内按 `[minGap, maxGap)`，再闭区间，再取最近带。命中后打底用 `rootProcessId`，盖面用 `capProcessId`。几何与切段仍按现网（实现圈 C8）。

工艺槽只引用身份，见 `工程与工艺引用.md`。

## 8. 旧工程只从厂端迁

云端没有文件树，不做自动映射。现场 App 不猜文件名、不扫 `/sdcard/ShiJiaoQi` 当导入器。

厂端一次性导入（本厂工艺工程师，作用域覆盖该厂）：

1. 工艺文件（含 `Standard/` 与 `User/`）先入本厂工艺资产，得到稳定身份、修订、摘要；记下「相对路径 → 身份」。同一路径只入一次。
2. T 排工艺包按目录名 `数字H-min-max` 收成间隙带：打底/盖面两份工艺 → 一条 `gapBands` 的两个引用。
3. 工程文件入库为本厂工程。单层无包角参数 → 单层模版；有 `cornerGroupParams` → 包角模版；`multilayer_data.json` → 多层模版；`tbar/.../project_data.json` → T 排模版并写入该厂当时的间隙带。
4. 正文里每条 `processPath` 与内嵌 `process` 换成 `processId`，删掉路径和嵌参数。去重写入 `deps`。空路径保持空引用，不进 `deps`。
5. 改写后必须 `processId` ⊆ `deps`，否则整份拒绝，原件不入。

导入默认厂级。要升平台级走现有升档，导入当时不自动升。不可复制不因导入放宽。

覆盖安装后未导入的旧文件：Client 当不存在。列表、激活、焊接都不得去读它。

标准工艺包同样只在这次导入里变成资产；现场不再维护独立标准盘，也不再用 CDN zip 覆盖本机目录。

## 9. 谁允许做什么（本文件新增的）

| 谁 | 允许 | 拒绝 |
| --- | --- | --- |
| WAN 管理员 | 登记 Client 身份、改分厂；新建/改 T 排工程模版并下发 | 不读厂级/个人级原件；不代厂导入旧文件 |
| 本厂超管 | 签发/撤销节点凭证；设缓存上限；授权哪份工程给哪台 Client | 不执行导入；不读个人正文 |
| 本厂工艺工程师（作用域够） | 厂端导入旧工艺/工程；组包下发到已授权本厂 Client | 不在 Client 上扫文件树导入 |
| 本厂有效账号 | 在已绑定且已钉设备号的本机登录、领钥、激活已授权闭包 | 未登录、读不到设备号、他厂、未绑定 |
| 创建人 | 在获准本机激活自己的个人级 | 个人级下发到别人的机 |
| 其他人 | — | 一律拒绝 |

焊接中不得切换激活、不得撤该份缓存。凭证过期不得新激活，本次焊接继续。
