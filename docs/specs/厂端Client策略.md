# 厂端 Client 策略

> 厂端功能，对本厂全部 Client 生效。WAN 不持这份。Client 只收、不改。  
> 不改工程/工艺正文形状。密文落盘、使用时内存明文，已拍。  
> 补充：`厂端到控制器.md`、`04-工程闭包.md`、`控制器Client.md`、`正文加密.md`。

---

## 1. 本圈目标

本厂一份**统一策略表**，超管可改。登录后 Client 按表同步**当前登录人获准**的工程与工艺（密文）；使用时内存明文。

现有 `factory_settings.max_cached_projects` 并进这张表，不另起第二套真相。

---

## 2. 缓存什么

登录或回连成功后，按策略拉取并写入本机袋（信封，无明文）：

- 该人获准使用的**工程闭包**（含 `deps` 里的工艺成员密文）
- 本机判定所需的**人员元数据**（稳定身份、显示名、角色与作用域）

不含：密码、会话令牌原文、解包后的工艺/工程明文、他厂数据、全厂账号库。不可复制平台级工艺仍不在厂端展示正文；下发到 Client 的仍是信封。

换人登或退出：本机有工程/工艺「改过」必须先提示；确认后清本机缓存（信封、焊接待发、内存钥与明文）。不确认则不退出、不清库。下一任必须重新登录再拉。

---

## 3. 使用时

激活、焊接、读参数：在内存解开该份明文工作副本。用完清工作副本。列表/状态只看元数据，不解正文。

---

## 4. 策略表（本厂一行，对本厂所有 Client）

只本厂超管写。升高修订，经厂→Client Intent 推送；Client 只接受更高修订。未连网用本机已持的那一版。

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `max_cached_projects` | 每台 Client 工程份上限，至少 1 | `2`（已有） |
| `cache_scope` | `current`：只缓存当前激活工程及其成员工艺；`all`：该人获准的全部（仍受上限） | `all` |
| `persist_unwrap_key` | 解封钥是否落盘（包装材料，**不是**工艺明文） | `false` |
| `key_ttl_seconds` | 解封钥时效；`0` = 仅进程存活（退出/销毁即清） | `0` |

其余键本厂可加；Client 不认识的忽略，不得当失败。

超上限再收新工程份 → 拒绝，不自动踢正在焊接或当前激活的。`current` 切到未缓存的工程且离线 → 拒绝激活，须连网再拉。

### 4.1 解封钥

- `persist_unwrap_key=false`（默认）：钥只在内存；进程死必须再登录。禁止 Keystore 开机自动解库。
- `persist_unwrap_key=true`：盘上只存包装后的解封材料；明文仍不准落盘。时效内进程重启可再解；到期销毁材料，必须再登录。仍禁止无登录开机自动解明文。
- `key_ttl_seconds>0`：到期清内存钥（以及已落盘的包装材料）。焊接中不中断本次；结束后不得新解，须再登录。

厂租约到期仍不停现场已领钥、凭证未过期的这一焊。

## 5. 谁允许

| 谁 | 允许 | 拒绝 |
| --- | --- | --- |
| 本厂超管 | 改本厂这一行策略 | 不读个人正文 |
| 本厂 Client | 收更高修订并按表缓存/领钥 | 改表 |
| WAN / 他厂 / 其他人 | — | 一律拒绝 |

审计：改键、旧值/新值、结果；无钥原文、无正文。

---

## 6. 不做

- 不把策略做成每人一份或每台 Client 一份（本期全局统一）。
- 不把全厂账号库或密码同步到 Client。
- 不因 `persist_unwrap_key=true` 把工艺/工程明文写入磁盘。
- 不改工程 JSON 字段。

---

## 7. 验收（条件 → 允许/拒绝）

1. 超管改 `cache_scope=all` → 允许；本厂 Client 回连后按该人获准拉齐（受上限）。  
2. `cache_scope=current` 且本机无该工程信封、离线 → 拒绝激活。  
3. `persist_unwrap_key=false` 杀进程后再开、未登录 → 拒绝解明文。  
4. `persist_unwrap_key=true` 且未过 `key_ttl_seconds` 杀进程再开、已登录过仍持包装材料 → 允许再解；过期 → 拒绝，须再登录。  
5. 非超管改表 → 拒绝；表不变。  
6. 落盘可见工艺明文或钥原文 → 拒绝（视为实现错误）。  
7. 换人后用前人个人级信封 → 拒绝（打开的是自己的库，前人的文件不打开）。
8. 有工程/工艺「改过」时退出未确认 → 拒绝退出，本机不变。确认后按这个人的留库设置：默认留下库文件并清掉内存会话；设成不留则删掉这个人的库文件。
