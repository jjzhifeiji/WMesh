# 焊长与时长统计

> 依据 `docs/平台架构核心需求.md` 本地状态（累计统计）与账号统计口径。  
> 本圈指标：焊长、时长、次数。WAN 只收无人员组织的汇总。

## 1. 采集

三种焊接模式共用一个采集器。口径与现场示教器一致：焊点 START 开计、END 关计；焊长按焊点段长（急停再补一段直线，毫米取整）；时长在焊接中、未暂停、开计时每秒 +1。空跑（焊长与时长都是 0）不入队。

## 2. 归属

每焊完一次（起停）产生一条运行事实：产生端发号、创建人=当时登录人、发生时组织路径快照、当时工程身份与名称快照、焊接模式（单层 / 多层 / T 排）、Client、增量焊长毫米、增量时长秒、发生时间。未打开工程记为空，事后改工程名不改已入队事实。同一台机上多人分账，互不混入对方累计。未登录不计。

组织路径在登录时按当时有效分配快照；无分配则记厂直属。事后改分配、改树、清屏都不改已入队或已汇聚的事实。

## 3. 本机

待发队列跟设备走，不跟登录人清空：A 未上传，B 登录后回连，A 与 B 的待发一起送，厂端按创建人分开落库。示教器屏幕累计只显示当前登录人；点数字清零只清该人本机显示，不动队列、不改厂端。

登录或回连时：该人尚无本机显示记录，则显示=厂端已汇聚合计+本机未上报；已有显示（含清零后的 0）不覆盖。换人先把上一任未结束的一焊入队。

登录人可在个人中心看自己的精简统计：合计次数 / 总焊长 / 总时长，按工程的次数与合计，以及最近每次（时间、时长、焊长）。含本机未上传。清零不影响此页。

## 4. 汇聚

连上本厂后，当前会话把本机全部待发送出（不要求发送人等于创建人）。按产生端身份幂等：字段相同仍一行；任一字段不同则拒绝覆盖，该条留在本机。创建人必须是本厂人员。厂库新表 `weld_facts`，不改 `fact_stubs` 列。厂端按日、工程名、模式收成汇总，经厂钥 HTTPS 上送 WAN；不上送人员、组织、路径。

## 5. 报表

厂端可按工程、人员、发生时组织路径、日查看次数 / 总焊长 / 总时长，并下钻到每次起停。超管看全厂；组织管理员/负责人/审计员看作用域；操作员只看自己。历史不随调动改写。超管可幂等写入演示焊次，供联调查看。

WAN 只按工厂、日、工程名、模式看次数 / 总焊长 / 总时长，不下钻到人。厂端连上或汇聚后自动覆盖该厂云端汇总。
