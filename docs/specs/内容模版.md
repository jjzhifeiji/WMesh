# 内容模版：工艺字段表 / 独立工程模版

> 依据 `docs/平台架构核心需求.md` §1：工艺与工程以设备已有明文为准；字段可随业务增减，不在核心需求里写死。  
> 不改阶段 1～5 的允许/拒绝、归属、升档与闭包组包。治理仍按正文摘要与修订。  
> 工程只引用工艺身份，见 `工程与工艺引用.md`。

---

## 1. 本圈目标

云端维护**当前**内容模版：工艺仍是一份字段表；工程是多份**完全独立**的模版（自己的名称、字段表、修订）。**只有新建**按当前模版套用；已有正文继续有效，改模版、改正文、升档、复制都不改写旧 JSON。

厂端与平台级工艺同一通道：每份模版各自推快照；厂库按 `(身份, 修订)` 收副本。工程模版按身份取最高修订，互不顶替。

---

## 2. 本圈不做

不发明设备里没有的工艺业务版本号。不改账号、节点凭证、闭包成员算法。不把模版当可复制/可升档的焊接资产。Client MQTT 仍未铺，本机袋不另存一份模版。工艺模版保持字段表，本圈不改。不做工程模版收回（删除后 WAN 不再下发，厂端已收副本仍在）。

---

## 3. 两种模版，不要混

| | 工艺 | 工程 |
| --- | --- | --- |
| **管什么** | 全平台一份字段表 | 多份独立模版，每份一份对象字段表 |
| **修订** | 这一份自己的 | **每份自己的**（改单层焊道不影响包角） |
| **新建资产** | 按字段表套键 | 正文从空数组起，只许按已有模版添加 |
| **人改什么** | 字段（键、名、类型、单位、默认、必填、嵌套） | 这一份的名称和字段表，完全自定义 |
| **管理台** | 导出 / 导入 / 保存 | 每份新建、编辑、删除立刻生效；不要整页导出导入恢复保存；不要选种类、不要附加工艺开关 |

没有系统默认字段表给新建用。空库先落下目前已有的四份（单层焊道 / 多层焊缝 / 包角 / T排对接），字段就是现在这四份自己的明细；之后新建从空字段起。已有库不自动插入第四份，由 WAN 管理员补建，不改已有工程正文。

工艺槽只引用身份，不嵌电流电压。点列、位姿、关节角、偏移、包角几何属于工程字段，由该份自己的字段表决定。

稳定身份不因改内容而换。改了则升高该份修订，只向前。摘要是规范 JSON 的 SHA-256，对不上不得用。

只有 WAN 管理员能改模版。厂与个人不得改原件。没有草稿/停用。写入只下发，不套已有资产。

### 3.1 工艺

根是对象。字段类型：文本（`string`）/ 枚举（`string` 加 `options`）/ `object` / `array`。旧 `number`、`bool` 仍能套用。参数名保持行业用语。初始字段来自设备已有工艺明文。

### 3.2 工程模版

每份根是对象，字段类型与工艺相同，另有 `process`（工艺引用）。名称必填、不重复；允许一份都没有。新建不预填字段。

工程正文是焊缝数组。每个元素带 `templateId`，套**那一份**的字段表。

T 排是独立一份，不得把坡口点或间隙带塞进单层。空库 T 排字段：身份、名称、点列（含起安/坡口四点/算出的起终点/终安）、选中点、启用、`gapBands`（`minGap` / `maxGap` / `layer` / `rootProcessId` / `capProcessId`）。禁止文件夹路径，禁止内嵌打底/盖面参数。

---

## 4. 套用

**仅新建**时套用，再算摘要、再落库。

工艺：缺的键补默认，多的键删除；嵌套同样套；非 JSON 或根类型不对则从空对象再补。

工程：非数组当空数组。每个元素按 `templateId` 套那一份对象字段，并写上 `templateId`；对不上的元素丢掉。空内容就是 `[]`。改正文不套用。

改正文、复制、升档、改模版：不套用，旧 JSON 原样有效。已送达闭包快照不动。平台级只读副本不就地改写。

---

## 5. 厂端

回连补送当前工艺一份加全部工程模版；云端改某一份后向在线厂推该份新修订。厂库存 `(身份, 修订)` 副本，工程按身份取最高修订。收到副本不改已有厂级/个人级正文。

厂内**新建**：有对象字段表的工程模版副本则必须按份套用；还没有副本时先按原样写入。改正文不套。不得改副本，不得把模版写进 `assets`。厂端不另开工程模版页。

---

## 6. 谁允许

| 谁 | 允许 |
| --- | --- |
| WAN 管理员 | 读/改工艺模版并下发；对每份工程模版独立新建/编辑/删除并下发；不改已有正文 |
| 本厂有效账号 | 读本厂已收模版副本；新建时按副本套用；工艺在参数里选，不另填依赖 |
| 其他人 | 拒绝 |

审计：改模版、新建套用、下发/接收；无正文原文、无密钥。

---

## 7. 验收

1. 云端改工艺模版加字段 → 已有平台级工艺正文不变、修订不变。  
2. 随后新建工艺 → 落库正文已套新模版（含新字段、无多余键）。  
3. 改正文、复制、升档不套模版，旧键保留。  
4. 厂收到更高修订模版副本后，已有厂级/个人级正文不变；之后新建才套。  
5. 非管理员改模版 → 拒绝。  
6. 摘要对不上的模版不得套用。  
7. 厂尚未收到工程模版副本时新建 → 正文原样。  
8. 工程字段类型为工艺时，该处为工艺下拉；旧模版键 `processId` 的文本仍当引用。  
9. 空库有四份独立工程模版（单层焊道 / 多层焊缝 / 包角 / T排对接），各带自己当前字段；新建工程套用后是空数组。  
10. 按某份添加一条，正文只含该份字段和 `templateId`。  
11. 改一份工程模版（改名或改字段）只升这一份修订；已有工程正文不变。  
12. 新建工程模版：名称必填，字段从空开始；无名称不得写入。  
13. 删除一份工程模版立刻从 WAN 当前列表消失；已有工程正文不变。
